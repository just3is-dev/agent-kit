argument-hint: "[NNN] — спека; без аргумента — из текущей ветки spec/*"

Ответь на один вопрос: делает ли код то, что написано в спеке. Спека
всегда права: расхождение — это дефект кода, не спеки. Ничего не правь,
только сверяй и предлагай.

1. **Прочитай спеку** `docs/specs/NNN-*.md` (`$ARGUMENTS` или номер из
   ветки `spec/NNN-*`). Статус `draft` — остановись: сверять нечего, спеку
   сначала утверждают.
2. **Прогони проверки.** `./scripts/check` и `./scripts/test`. Красные —
   сверка не имеет смысла, покажи вывод и остановись.
3. **По каждому критерию приёмки** (зачёркнутые пропускай) определи
   статус, в этом порядке:
   - **тест**: есть тест с именем `AC-N: ...` (grep по тестам проекта, без
     node_modules/.venv/.build), он зелёный и по смыслу проверяет именно
     этот критерий, а не приклеен к чужому. Укажи файл:строку;
   - **код**: теста нет, но поведение реализовано — найди место в файлах
     из `covers:`;
   - **не найден**: ни теста, ни кода;
   - **противоречит**: код делает иначе, чем сказано в критерии. Укажи где.
4. **Проверь остальное:**
   - все задачи в «Задачах» отмечены `[x]`; неотмеченные при готовом коде
     — расхождение документа;
   - файлы, изменённые в ветке спеки (`git diff main...HEAD --name-only`),
     но не покрытые `covers:` — перечисли: либо `covers:` неполон, либо
     код вышел за границы спеки;
   - «Границы»: дифф не реализует того, что спека обещала не делать.
5. **Отчёт.** Таблица «Критерий | Статус | Где», затем список расхождений
   из п. 4, затем вывод:
   - все критерии — «тест», расхождений нет → предложи `status: done`;
   - есть «код» → спроси одним AskUserQuestion: дописать тесты или принять
     как есть;
   - есть «не найден» или «противоречит» → предложи `/work NNN` или
     `/work NNN.K` для конкретной задачи. Если по твоему мнению неправа
     спека — отдельной строкой «Если неправа спека: ...», решение за
     пользователем, спеку не меняй.
6. **Завершение** (после согласия пользователя): `status: done`, коммит
   `docs: SPEC-NNN done [SPEC-NNN]`. Предложи merge:
   `git checkout main && git merge --squash spec/NNN-<слаг>` и коммит
   `<type>: <название спеки> [SPEC-NNN]`. Выполняй только по явному «да».
