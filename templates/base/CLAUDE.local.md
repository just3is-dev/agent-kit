# Локальные правила (agent-kit)

Это чужой проект: его собственные конвенции (стиль коммитов, ветки, язык,
структура) всегда побеждают правила ниже. Файл не коммитится.

## Контракт

- `./scripts/check [файлы...]` — типы и линт
- `./scripts/test` — все тесты
- `./scripts/fix [файлы...]` — автоформат

Скрипты лежат в репозитории, но исключены из git через `.git/info/exclude`.
Хуки зовут их сами. Обходить проверки запрещено.

## Процесс

- Спеки в `docs/specs/` (тоже исключены из git), задачи — чеклист в спеке.
- Перед PR — `/review`, потом сам читаешь дифф.
- Правки «заодно» не делаются; найденное — в `docs/backlog.md`.
