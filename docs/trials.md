# Обкатки

Плагин проверялся на реальных и пробных проектах. Списки находок жили
в этой папке, пока правки не были применены; теперь они в истории git
(`git log --all -- docs/trial-*.md`), здесь — итог.

| Обкатка | Когда | Что проверяли | Находок | Закрыто |
|---|---|---|---|---|
| 1. Лендинг на Astro | 2026-10-17…24 | пять спек на своём проекте, две с подключённым плагином: `/spec`, `/work`, `/verify`, хуки с живым человеком | 23 | 0.1.2 |
| 2. Четыре стека | 2026-10-30 | субагенты: `/init` → hello world → `/verify` на node, python, swift-ios, monorepo; init на существующем проекте | 25 | 0.1.3 |
| 3. Чужой проект и sync | 2026-10-30 | `/init --local` на репозитории со своими конвенциями; `/sync` на четырёх проектах, включая локально правленный скрипт | 19 | 0.1.4 |

## Что показали

- Шаблоны стеков рабочие: ни одного устаревшего флага на Xcode 16, Node 24,
  uv 0.13. Проблемы были в текстах команд и на стыках правил.
- Самые частые классы находок: текст команды не описывает случай (node
  без генератора, uv без флагов, монорепо с workspaces); хук мешает
  правилу (check блокирует тест на ещё не написанную функцию); команда не
  знает, что проект чужой (ветка, коммит, спека вне git).
- Плагин из локального клона кэшируется и не обновляется сам: обкатки 2
  и 3 шли на текстах команд версии 0.1.1. Находки сверялись с рабочей
  копией; в README добавлен `claude plugin update`.

## Что не проверено

- Stop-хук с живым человеком после 0.1.2: субагенты вызывают
  `SubagentStop`, его в плагине намеренно нет.
- Точки решений человека на чужом проекте: утверждение спеки, выбор
  ветки, текст PR — в обкатке 3 их принимал агент.
- Установка из GitHub-источника в `settings.local.json`.
