# Обкатка 3: `/init --local` на чужом проекте и `/sync` (2026-10-30)

Два субагента. Первый построил «чужой» node-проект (ESM, ESLint 9 flat,
Jest, свой CLAUDE.md, CONTRIBUTING с английскими коммитами `type(scope):`,
ветками `feature/*` и обязательным PR), подключил плагин через
`/init <путь> --local` и прошёл spec → work → verify. Второй прогнал
`/sync` на четырёх проектах обкатки 2, где скрипты отстали от шаблонов
0.1.3, включая скрипт с локальной правкой и скрипты без маркера.

**Про стенд.** Команды и хуки в сессии грузились из кэша плагина
`~/.claude/plugins/cache/agent-kit/agent-kit/0.1.1` (коммит ba19552 от
24.10): marketplace с источником `directory` копирует плагин при
установке и сам не обновляется. Так было и в обкатке 2. Шаблоны агенты
читали из рабочей копии по указанному пути. Все находки ниже сверены с
текущей рабочей копией; кэш обновлён `claude plugin update`.

## `/init --local`: что утекло в git

Контракт с ESLint и Jest заработал без правок, чужой CLAUDE.md и CI не
тронуты, `.git/info/exclude` заполнен. Но после буквального выполнения
`git status` показал четыре изменённых tracked-файла.

1. **`.gitignore` дописан** 19 строками из `templates/base/gitignore`,
   включая python- и swift-мусор в node-проекте. Правка: при `--local`
   `.gitignore` не трогать, недостающее — в `.git/info/exclude`; base
   gitignore разбить по стекам или оставить только общее.
2. **`npm i -D prettier`** изменил `package.json` и `package-lock.json`:
   init.md требует prettier как минимум. Правка: при `--local` ничего в
   манифест не ставить, prettier считать необязательным.
3. **`scripts/fix` без prettier в проекте** молча скачал его через `npx` и
   переформатировал чужой `tsconfig.build.json` дефолтами. Правка: `fix`
   проверяет prettier в devDependencies (как линтер) и молчит без него;
   `npx` без автоустановки (`--no-install`).
4. **`docs/` целиком в exclude** скрывает и будущие чужие `docs/*`.
   Правка: исключать точечно `docs/specs/`, `docs/adr/`, `docs/backlog.md`.

## `/init --local`: команды не знают, что проект чужой

5. **Спеку нельзя закоммитить:** `docs/specs/` исключена из git, `git add`
   отвечает «paths are ignored». Коммиты `docs: спека …` и
   `docs: SPEC-NNN done` в spec.md и verify.md невозможны. Описание задачи
   для PR никуда не попадает. Правка: в `--local` коммит спеки
   пропускается, `/verify` в конце предлагает текст PR из «Зачем», «Что
   делаем» и критериев.
6. **Ветка `spec/NNN-*` против `feature/<name>`:** work.md п. 2 «ты в другой
   ветке — остановись» формально останавливает каждый `/work`; `/work` и
   `/verify` без аргумента берут NNN из имени ветки. Правка: ветка `spec/*`
   только если у проекта нет своей конвенции; NNN без аргумента — из
   единственной `approved`-спеки, если ветка не `spec/*`.
7. **Коммиты:** сделаны по-чужому (`feat(slugify): add separator option
   [SPEC-001.1]`), токен оставлен, хотя для upstream он бессмысленен.
   Правка: в `--local` токен опционален, формат сообщения — чужой.
8. **Squash в main** из verify.md противоречит «PR обязателен». «Только по
   явному да» защищает, но само предложение чужую конвенцию игнорирует.
   Правка: при `--local` предлагать PR, не squash.
9. **Фразы «чужие конвенции побеждают» в CLAUDE.local.md недостаточно:**
   команды её не читают и содержат императивы, а при сессии не в корне
   проекта файл вообще не в контексте. Правка: одна строка в work/verify
   «CONTRIBUTING или свои правила проекта приоритетнее», в init `--local`
   — требование открыть сессию в папке проекта.
10. **Язык имён тестов:** скилл tdd даёт русский пример, в английском
    проекте агент писал по-английски, grep нашёл. Правка: «язык
    утверждения — язык проекта».
11. **Повисший тест:** красный тест с бесконечным циклом повесил jest,
    `scripts/test` без таймаута. Скилл tdd случай «тест висит» не
    оговаривает. Правка: в tdd «висит дольше минуты — прерви, это тоже не
    красный тест»; таймаут в шаблонах не добавлять.

## `/sync`

Все четыре прогона прошли: монорепо обновил шесть пакетных скриптов,
диспетчер в корне был актуален; swift — только `check`; python — только
`ci.yml`; node — `test` и `fix`, `check` с локальной правкой оставлен и не
изменился. Права сохранены, контракты зелёные. Скрипт без маркера показан
как «не сравниваю».

12. **Git после sync не описан:** во всех проектах изменения остались
    незакоммиченными, тогда как `/init` и `/work` коммитят. Правка: шаг
    «коммит `chore: обновить скрипты agent-kit`» или явное «не коммитит».
13. **Маркер неизвестного стека** (`# agent-kit/rust`): шаблона нет,
    поведение не задано. Правка: «нет `templates/<стек>` — показать как
    неизвестный плагину, не сравнивать».
14. **Локальная правка блокирует обновление:** diff показывает дрейф
    шаблона и локальные строки одним куском, выбор только «заменить или
    оставить». Правка: третий вариант «заменить и перенести локальные
    строки» (агент видит оба файла, перенос ему по силам).
15. **`scripts/lib.sh` не сравнивается** (swift-ios), хотя копируется при
    init. Правка: добавить в шаг 3.
16. **«Первая строка комментария»** читается как строка 2 после shebang;
    комментарий выше маркера сделает скрипт «ручным». Правка: «первая
    строка, начинающаяся с `# agent-kit/`».
17. **Стек `ci.yml` в монорепо** не определён. Правка: по маркеру
    корневого `scripts/check`.
18. **`scripts/fix` никогда не вызывается в цикле:** первый ручной запуск
    переформатировал `docs/*.md`, tsconfig и тесты, закоммиченные `/init`
    и `/work` без форматирования. Правка: `/work` зовёт `scripts/fix` по
    изменённым файлам перед коммитом; `/init` — перед первым коммитом.
19. **«Красный контракт — откати этот файл»** при обновлении шести файлов
    неоднозначно, какой. Правка: «откати все обновлённые в этом прогоне».
