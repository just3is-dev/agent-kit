# Обкатка 2: node, python, swift-ios, monorepo (2026-10-30)

Четыре субагента параллельно, каждый на пустом проекте в scratchpad:
`/init` → `/spec` «hello world» → `/work` по задачам → `/verify`.
Команды вызывались через Skill как плагин, хуки были активны. Монорепо —
на заранее подготовленном каркасе (npm workspaces), это заодно сценарий
«init на существующем проекте». Пользователя не было: спеки утверждали и
squash делали сами, все такие места агенты отмечали.

| Стек | Цикл | check | test | Итог |
|---|---|---|---|---|
| node | пройден | 0.5–1.0 с | 0.4–1.1 с | ОК, замечания по init |
| python | пройден | 0.2–0.3 с (2.4 холодный) | 0.3–0.8 с | хук заблокировал первый тест (п. 7) |
| swift-ios | пройден | 0.3–0.6 с | 2–7.5 с (35 с первый) | ОК, нет образца project.yml |
| monorepo | пройден с обходом | 1.1 с | 0.9 с | контракт красный после init (п. 6) |

Шаблоны везде оказались рабочими: флаги, версии инструментов, CI на
Xcode 16.2 / Node 24 / uv 0.13 — всё запускается. Проблемы в тексте
команд и на стыках правил.

## Сквозные находки (во всех стеках)

1. **`$ARGUMENTS` подставляется в заголовки** `commands/spec.md:12,45` и
   в описание `--local` в `init.md:9`. Агент видит «## Изменение спеки
   (`CLI печатает ...` — `NNN: ...`)». Косметика, но сбивает все четыре
   раза. Правка: одна строка «Аргумент: $ARGUMENTS» вверху, в тексте —
   слово «аргумент».
2. **stop-test не видит проект вне корня сессии.** Хук берёт
   `${CLAUDE_PROJECT_DIR:-$PWD}`; `/init <путь>` в другой папке даёт
   проект, где Stop-гейт никогда не сработает, а отчёт init обещает
   «хуки уже активны». Плюс для субагентов событие `SubagentStop`, его в
   hooks.json нет — ни один из четырёх прогонов не гонял тесты на Stop.
   Правка: в отчёте init предупреждать «Stop-хук работает для проекта в
   корне сессии, откройте сессию в папке проекта»; `SubagentStop` —
   решить отдельно (субагенты в процессе не предусмотрены).
3. **Имя теста `SPEC-NNN AC-N: ...` не выражается именем функции** в
   pytest и XCTest. Агенты положили маркер в docstring / комментарий над
   методом, `/verify` нашёл grep-ом. Правка: в `skills/tdd` одной
   строкой: «где имя не может содержать пробелы — маркер в docstring или
   комментарии над тестом».
4. **Красный tsc/swift build на свежем тесте до реализации.** post-edit-check
   блокирует Write теста, который импортирует ещё не существующую
   функцию (TS2305 в node/monorepo, не компилируется в swift). Это не
   ложное срабатывание, а конфликт «сначала падающий тест» с хуком.
   Правка: в `skills/tdd` — «для компилируемого кода сначала заглушка без
   поведения, потом красный тест; если хук упал на отсутствующем символе,
   следующая правка — реализация».
5. **guard ложно режет `echo "... git commit --no-verify"`.** Трижды.
   Документировано как приемлемое, оставить; при желании сузить до
   начала команды: `(^|[;&|][[:space:]]*)git[[:space:]]`.

## Стековые находки

6. **node-шаблон в монорепо: контракт красный сразу после init.**
   `check`/`test`/`fix` ищут oxlint/vitest только в package.json своего
   пакета, а в workspaces dev-зависимости живут в корне. Обход агента —
   дублировать devDependencies в каждый пакет. Правка: в `node -e` при
   определении инструмента подниматься по родительским package.json
   (или `require.resolve`), либо в init.md для monorepo явно: «dev-зависимости
   объявляются в каждом пакете».
7. **python: mypy через хук блокирует первый тест с импортом пакета**
   (`import-untyped: missing py.typed`). uv ставит пакет editable, mypy на
   одном файле резолвит его из site-packages. Починено файлом
   `src/<pkg>/py.typed`. Правка: init для python создаёт `py.typed`, шаг 5
   проверяет контракт на тесте с импортом пакета, не на пустом наборе.
8. **python: `uv init` не задан флагами.** Голый `uv init` даёт `main.py`
   в корне, делает свой `git init` не в `main` и берёт authors из git
   config (реальные имя и email в pyproject). Агент взял
   `uv init --package --vcs none --name ... --description ...`. Правка:
   прописать команду в init.md шаг 2, добавить `--author-from none` или
   предупреждение.
9. **python: нет проверки `uv`.** На машине его не было, init не
   предупреждает. Правка: «нет `uv` — остановись, предложи
   `brew install uv` / `pipx install uv`».
10. **python ci.yml: `setup-uv@v5`** (есть v7), `uv sync --dev` — флаг
    лишний. Правка: `@v7`, `uv sync`.
11. **node: нет образца для CLI/библиотеки.** init.md предлагает только
    create-next-app и nestjs; агент взял `npm init -y` + tsconfig вручную.
    Правка: вариант «библиотека/CLI: `npm init -y`, tsconfig NodeNext,
    vitest».
12. **node: нет `templates/node/tsconfig.json`**, а `check` зовёт `tsc`.
    Без tsconfig tsc падает; tsconfig с `include: ["src"]` оставляет
    тесты без тайпчека. Плюс Node 24 запускает `.ts` без сборки, но
    импорты `./x.js` при этом не резолвятся: нужен
    `rewriteRelativeImportExtensions` (TS ≥ 5.7). Правка: шаблонный
    tsconfig (`include: src, tests`, NodeNext, `rewriteRelativeImportExtensions`).
13. **TypeScript 7 ставится по умолчанию** (`npm i -D typescript` → 7.0.2,
    нативный tsc). Работает, но в монорепо не подхватывает `@types/node`
    из родительского node_modules: нужен `types: ["node"]` в tsconfig
    пакета. Правка: в init.md рядом с `@types/node`.
14. **init.md: «vitest без Vite требует `vite`» устарело** — vitest 5 тянет
    vite сам. Правка: убрать фразу.
15. **init.md: порядок правил определения стека.** «package.json → node»
    стоит раньше «apps/*, packages/* → monorepo»; корневой package.json с
    workspaces читается буквально как node. Правка: monorepo первым или
    «`workspaces` в package.json → monorepo».
16. **node/astro `fix` не молчит**: prettier печатает строку на файл.
    Правка: `--log-level warn`.
17. **swift-ios: нет образца `project.yml` и точки входа.** Агент выдумал
    bundle id, deployment target, `CODE_SIGNING_ALLOWED: NO`. Правка:
    `templates/swift-ios/project.yml` и `App.swift`-скелет.
18. **swift-ios: политика `.xcodeproj` в git не зафиксирована.**
    `scripts/test` перегенерирует его при наличии `project.yml`; агент
    добавил `*.xcodeproj/` в .gitignore. Правка: зафиксировать в
    шаблоне.
19. **swift-ios: post-edit-check падает на промежуточных состояниях
    SPM-пакета** (Package.swift без Sources, Sources без Tests —
    «target is empty», «overlapping sources»). Агент продолжал. Правка:
    в `check` пропускать `swift build`, пока у пакета нет `Sources/`.
20. **swift-ios: `check` без аргументов шумит** «Planning build… Build
    complete!». Правка: `swift build -q`.
21. **verify.md п. 4: «конфиги в корне»** — в монорепо tsconfig лежит в
    корне пакета. Правка: «в корне проекта или пакета».
22. **init.md шаг 3: удаление условных секций CLAUDE.md** описано только
    для миграций, а «Внешние материалы» с таким же условием — нет.
    Правка: «удали секции с комментарием-условием, если условие не
    выполнено».
23. **init.md шаг 1: пустая папка — стек не спросить.** Вопрос для пустого
    проекта содержит название и описание, но не стек. Правка: добавить
    выбор стека в тот же вопрос.
24. **`templates/base/CLAUDE.local.md:18` упоминает `/review`**, которого
    в плагине нет. Правка: убрать строку.
25. **monorepo: корневые файлы никто не проверяет** (CLAUDE.md,
    package.json, .github). По дизайну; упомянуть в README.

## Что обкатка не покрыла

- Утверждение спеки, подтверждение «противоречит» в verify и «явное да»
  на squash — всё приняли агенты. Поведение команд в этих точках с живым
  человеком видно только по обкатке 1.
- Stop-хук (п. 2) не сработал ни разу; его проверяли только smoke-тесты
  плагина и ручной запуск скрипта.
- `/init --local` на чужом репозитории и `/sync` по-прежнему не
  запускались.
